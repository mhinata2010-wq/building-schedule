# UI reference direction

Primary reference: Ryota Kikuchi's UI inspiration article.

## Applied principles
- Start from the user's operation, not decoration.
- Separate primary information from secondary explanation.
- Keep color roles limited and predictable.
- Connect status/information directly to the next action.
- Use Japanese labels and realistic information density.
- Reuse a small set of spacing, radius, border, and typography tokens.
- Keep the Gantt schedule as the dominant work surface rather than surrounding it with dashboard decoration.

## Product-specific decision
For this construction schedule prototype, the main action is drawing/editing bars. The interface therefore prioritizes the schedule canvas, uses a compact utility header, keeps the workflow explanation secondary, and presents network scheduling as a sibling view generated from the same data.
