# 工程の削除と後続工程の確認付き移動（2026-11-04）

## 操作
- 「工程を考える」では、各工程行のゴミ箱アイコンから工程を削除する。必ず削除確認を出す。工程の詳細パネルからも同じ削除処理を呼ぶ。
- 削除対象を前工程に指定している工程が存在する場合、確認文にリンク解除件数を表示。削除するとその工程の `pred` を空にする。後続工程自体は削除しない。
- ガントバーを後ろにドラッグしたときと、詳細パネルの「日程を確定する」を押したときは、変更後の終了日が変更前より遅ければ後続工程を探索する。
- 後続が存在する場合、「後続工程も変更しますか？」と1回確認する。承認の場合は対象工程とすべての未完了の後続工程を同じ日数だけ後ろへ移動する。否認の場合は選択中の工程だけ保存する。
- 前倒し、開始日のみの変更（終了日が変わらない）、後続工程がない場合は確認しない。
- `pred`（前工程ID）を通る依存関係で探索する。ガント上の行順だけでは動かさない。分岐した依存チェーンも対応し、各工程は1回だけ移動する。
- 完了済み（`done` または進捗100%）は履歴として動かさず、その先の自動移動も停止する。
- 期間（日数）と既存の空き日数を保持する。後続工程が変更に同意したときだけまとめて `persist()` で保存する。
- 移動で120日の表示範囲を超える場合は、表示終端を必要な範囲まで拡張する。

## 非対象
- 施工会社の休業日、土日祝日、人的リソース、開始制約を考慮した自動再計算
- 複数前工程（現行データモデルの `pred` は1工程のみ）
- 変更履歴・Undo・複数端末リアルタイム共同編集
